# ECCB 689 Special Topics
Modeling Ecological Niches and Species Distributions

## What is this course?
A project-centered, coding-based course using real data to build, evaluate, and interpret ecological niche models in R.

## Why take this course?
Gain practical modeling skills, produce a complete research workflow, and critically evaluate ecological models.
Structure
Weekly coding assignments (40%)
Term project (60%)
No exams
Reproducible workflows

## What will you do?
Work with real data
Build niche models
Evaluate predictions
Develop an independent project
